# Social Media Post

Write a post people stop scrolling for — in the voice of the user's brand,
shaped for the platform.

## Steps

1. Determine platform and goal (awareness, engagement, sales, hiring). If no
   platform is named, write one general version and offer platform variants.
2. Lead with a hook in the first line — a question, number or bold claim.
   The first line decides whether the rest is read.
3. Keep the body scannable: short lines, line breaks, at most one emoji per
   thought (none for formal LinkedIn tones).
4. End with a single clear call to action, then 3–5 relevant hashtags
   (skip hashtags for X/Twitter-style short posts).

## Output format

The post text ready to paste. If variants were requested, label each
(Facebook / LinkedIn / TikTok caption). Match the user's language — for
Vietnamese audiences, write natural Vietnamese, not translated English.

## Edge cases

- Regulated claims (health, finance): avoid absolute promises; suggest
  compliant phrasing.
- Trend references: only use ones the user supplied — never invent a trend.
